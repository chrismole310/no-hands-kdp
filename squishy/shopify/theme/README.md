# Theme files (Horizon)

Edited copies of the theme JSON pushed to the unpublished duplicate theme "Horizon - Deskloaf copy (Claude edits)" on 20 Sept 2026. The live theme is never written by the connector; a human previews the copy in Online Store → Themes and clicks Publish.

- `header-group.json`: announcement bar copy; country and language selectors hidden (US only).
- `index.json`: hero headline, sub-copy and "Shop bundles" button; a value-props block; product grids for Bundles and Desk Calm.
- `password.json`: "opening soon" page copy with email capture.
- `upsert_payload.json`: exact payload sent to `themeFilesUpsert`.
