# Repository guide

Two projects live here:

1. **No Hands KDP** (root): Amazon KDP / Draft2Digital upload automation. See `README.md`.
2. **Deskloaf** (`squishy/` and `research/squishy-store/`): a Shopify squishy-toy store being built and operated with Claude Code. **Start with `squishy/HANDOFF.md`** for current state, accounts, outstanding human tasks and guardrails.

Quick checks for Deskloaf: `python3 squishy/finance/bundle_margins.py`, `python3 squishy/shopify/setup_store.py --dry-run`.
